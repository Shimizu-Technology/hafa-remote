Hafa Remote is an iPhone-only local-network remote. No account or test credentials are required. This candidate is for internal TestFlight household verification; simulator testing does not certify public compatibility or physical-TV acceptance.

Without hardware: from first launch, Help → Try the Remote Offline opens a Release-compatible, explicitly simulated remote and connection/error states. It does not discover, pair, contact a TV, use pairing credentials, or save a real TV.

Live control: connect the iPhone by Wi-Fi and a compatible TV by Wi-Fi or Ethernet to the same non-guest local network. Choose Add TV, allow Local Network access, select the intended TV, and complete its on-TV approval/code. Discovery uses declared Bonjour services and bounded protocol-specific discovery; availability varies. TV not showing up? provides brand-aware manual private-address setup. My TVs manages selection, names, rooms, Add TV, and deliberate Forget TV. Saved identity is checked separately from discovery aliases/cached addresses; ambiguous aliases require explicit selection.

Samsung uses secure local WebSocket control on 8002; Sony uses Android TV Remote Service v2 TLS pairing/control on 6467/6466; Vizio uses local HTTPS on an allowlisted discovered/saved port, normally 7345 (legacy 9000 where applicable). Trust and Keychain credentials are scoped to the selected TV. Non-secret device metadata and per-TV preferences stay local. Arbitrary internet loads are disabled. There is no backend, analytics SDK, advertising, tracking, account, subscription, or in-app purchase.

Controls depend on capability evidence. Samsung shortcuts use a bounded TV-returned app list. Sony shortcuts are negotiated configured links, not installed inventory. Sony keyboard also requires an enabled per-TV preference and fresh focused-field/counter evidence; unsupported/stale fields produce a useful message. Vizio has returned inputs and ordinary current-app favorites, without guide, digits, or text. Requests are described as sent; TV execution is not asserted without acknowledgement.

Foreground recovery makes up to five automatic attempts, then offers available wake, Retry Connection, and Find TV. Power-off preserves the saved TV. Wake varies by model, firmware, standby settings, and network. Samsung's eligible saved wireless-TV path sends three unicast Wake-on-LAN packets; Sony/Vizio use their local power paths. No guaranteed wake, subnet-wide wake broadcast, or universal compatibility is claimed. The Control Center extension only opens the remote.

Help → Diagnostics is off by default and holds up to 100 semantic events/coarse timings in memory. Preview Support Report creates an immutable report with app/iOS versions and optional TV model/firmware, excluding addresses, credentials, identities, TV/Wi-Fi names, and entered text. Share This Report opens the system share sheet; the user chooses whether and where to send that exact report. Nothing is automatically uploaded. Clear Events/disable clears live events; an open preview stays unchanged.

External TestFlight/public submission remains gated on final-binary privacy answers, published support/privacy wording, hardware/model coverage, reliability evidence, and each local protocol's distribution basis. These notes prepare that later review; they do not approve it.
